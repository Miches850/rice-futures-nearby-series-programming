## Upload steps

1. Create the repository as **Private**.
2. Upload the contents of this package to the repository root.
3. Confirm the README image renders correctly.
4. Keep the repository private until the portfolio-wide correction pass.
5. If the 20 original contract files are later found, restore them under `data/raw/`.
6. Correct and validate the nearby rollover logic.
7. Recreate the derived workbook and plot.
8. Make the repository public after the corrected outputs match the documented method.
